Spring Boot 3 is about to reach its end of non-commercial support, and this post examines what that means for MQ's support of the Spring Boot environment. Version 3.5.15 of the MQ Spring Boot starter is the final release built for Boot 3, with future updates shifting focus to Boot 4, available since late 2025.
